# 账单导出钱迹格式功能说明

## 功能概述

账单列表页面新增"导出钱迹格式"按钮，支持将账单数据直接导出为钱迹记账 APP 可导入的 CSV 格式文件，无需再使用 Python 脚本手动转换。

## 钱迹格式说明

钱迹 CSV 格式包含以下 13 个字段（按顺序）：

| 序号 | 字段名 | 说明 | 转换规则 |
|------|--------|------|----------|
| 1 | 时间 | 格式：YYYY/MM/DD HH:MM | 交易日期 + 交易时间（格式转换） |
| 2 | 分类 | 一级分类 | 直接使用账单的"分类"字段 |
| 3 | 二级分类 | 二级分类 | 直接使用账单的"二级分类"字段 |
| 4 | 类型 | 收入/支出/转账 | 收支类型转换为中文 |
| 5 | 金额 | 交易金额 | 根据收支类型取对应金额 |
| 6 | 账户1 | 支付渠道 | 使用账单的"支付渠道"字段 |
| 7 | 账户2 | 转账目标账户 | 留空（暂不支持转账） |
| 8 | 备注 | 交易备注 | 优先使用"备注"，为空则使用"交易描述" |
| 9 | 账单标记 | 不计收支/预算/报销等 | "计入统计"为否时填"不计收支" |
| 10 | 手续费 | 手续费金额 | 留空（暂不支持） |
| 11 | 优惠券 | 优惠券金额 | 留空（暂不支持） |
| 12 | 标签 | 标签列表 | 格式：#标签1#标签2#标签3# |
| 13 | 账单图片 | 图片URL | 留空（暂不支持） |

## 使用方法

### 1. 前端操作

1. 进入账单列表页面
2. 根据需要设置筛选条件（日期、分类、标签等）
3. 点击"导出钱迹格式"按钮
4. 下载 CSV 文件（文件名格式：`钱迹导入数据_时间戳.csv`）

### 2. 导入钱迹 APP

1. 打开钱迹记账 APP
2. 进入"设置" → "数据管理" → "导入数据"
3. 选择"CSV 导入"
4. 选择下载的 CSV 文件
5. 确认导入

## 字段转换详细说明

### 时间格式转换
- **源格式**: 交易日期 `2026-08-14` + 交易时间 `11:26:46`
- **目标格式**: `2026/08/14 11:26`
- **规则**: 日期分隔符从 `-` 改为 `/`，时间只保留时和分

### 标签格式转换
- **源格式**: 数据库存储多个标签ID，逗号分隔
- **目标格式**: `#标签1#标签2#标签3#`
- **规则**: 每个标签前后都加 `#` 符号

### 账单标记转换
- **源字段**: `include_in_statistics` (0=不计入, 1=计入)
- **目标值**: 
  - `include_in_statistics = 0` → `账单标记 = "不计收支"`
  - `include_in_statistics = 1` → `账单标记 = ""`（空字符串）

## API 接口

### 导出钱迹格式
- **URL**: `/bill/exportQianji`
- **方法**: POST
- **请求参数**: `BillQueryDTO`（与列表查询参数一致）
- **响应类型**: `text/csv` (UTF-8 编码)
- **响应头**: 
  ```
  Content-Type: text/csv
  Content-Disposition: attachment;filename*=utf-8''钱迹导入数据_时间戳.csv
  ```

### 查询参数说明

支持的筛选条件：
- `transactionType`: 交易类型
- `categoryId`: 分类ID
- `subCategoryId`: 二级分类ID
- `paymentChannel`: 支付渠道
- `amountType`: 收支类型（INCOME/EXPENSE）
- `includeInStatistics`: 是否计入统计（0/1）
- `manualEntry`: 是否手动录入（0/1）
- `tagIds`: 标签ID列表
- `keywords`: 关键词搜索
- `minAmount`: 最小金额
- `maxAmount`: 最大金额
- `startDate`: 开始日期
- `endDate`: 结束日期

## 后端实现

### 核心类

1. **BillQianjiExportVO.java**
   - 钱迹格式导出 VO
   - 使用 EasyExcel 注解标注字段顺序

2. **BillService.exportQianjiBills()**
   - 查询账单数据
   - 转换为钱迹格式
   - 处理标签格式化

3. **BillController.exportQianji()**
   - 接收导出请求
   - 调用 Service 层
   - 返回 CSV 文件流

### 关键代码片段

```java
// 时间格式化
DateTimeFormatter dateFormatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
DateTimeFormatter timeFormatter = DateTimeFormatter.ofPattern("HH:mm");
String dateStr = date.format(dateFormatter);
String timeStr = time.format(timeFormatter);
vo.setTime(dateStr + " " + timeStr);

// 标签格式化
String tags = tagIds.stream()
    .map(tagId -> {
        BillTag tag = billTagMapper.selectById(tagId);
        return tag != null ? "#" + tag.getTagName() : null;
    })
    .filter(name -> name != null)
    .collect(Collectors.joining(""));
if (!tags.isEmpty()) {
    tags = tags + "#";
}
vo.setTags(tags);
```

## 前端实现

### API 调用

```javascript
// src/api/bill.js
export function exportQianjiBills(data) {
  return request({
    url: '/bill/exportQianji',
    method: 'post',
    data,
    responseType: 'blob'
  })
}
```

### 下载处理

```javascript
// src/views/BillList.vue
const handleExportQianji = async () => {
  try {
    exportingQianji.value = true
    const res = await exportQianjiBills(exportQuery)
    
    // 创建下载链接
    const blob = new Blob([res], { type: 'text/csv;charset=utf-8' })
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    const timestamp = new Date().toISOString().replace(/[:\-T]/g, '').split('.')[0]
    link.download = `钱迹导入数据_${timestamp}.csv`
    document.body.appendChild(link)
    link.click()
    document.body.removeChild(link)
    window.URL.revokeObjectURL(url)
    
    ElMessage.success('导出钱迹格式成功')
  } catch (error) {
    console.error('导出钱迹格式失败:', error)
    ElMessage.error(error.message || '导出钱迹格式失败')
  } finally {
    exportingQianji.value = false
  }
}
```

## 注意事项

1. **字符编码**: CSV 文件使用 UTF-8 编码（带 BOM），确保中文正常显示
2. **字段顺序**: 严格按照钱迹官方格式的字段顺序导出
3. **空值处理**: 空值字段导出为空字符串，不能省略
4. **标签格式**: 标签必须使用 `#标签名#` 格式，前后都要有 `#`
5. **时间格式**: 时间格式必须是 `YYYY/MM/DD HH:MM`，不能使用其他格式
6. **账单标记**: 只支持"不计收支"标记，其他标记暂不支持

## 对比 Python 脚本

### 优势
✅ 无需额外脚本，直接在系统中一键导出  
✅ 实时数据，无需先导出 Excel 再转换  
✅ 支持筛选条件，灵活导出指定数据  
✅ 自动处理标签格式化  
✅ 集成在账单列表页面，操作便捷  

### Python 脚本 (docs/qianji/bill_to_qianji.py)
- 需要先导出 Excel
- 需要安装 Python 和 pandas 库
- 需要手动运行脚本
- 两步操作流程

### 功能对比

| 功能 | Python 脚本 | 系统导出 |
|------|-------------|----------|
| 数据源 | Excel 文件 | 数据库直接查询 |
| 操作步骤 | 2步（导出Excel + 运行脚本） | 1步（点击按钮） |
| 筛选条件 | 不支持 | 支持完整筛选 |
| 标签处理 | 不支持 | 自动格式化 |
| 实时性 | 需先导出 | 实时查询 |
| 依赖 | Python + pandas | 无需额外依赖 |
